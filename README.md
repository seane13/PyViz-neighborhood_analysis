## San Francisco Neighborhood Data Analysis 

This project analyzed the sales and rental data from San Francisco neighborhoods from 2010 to 2016. The project includes charts and plots from Pandas, Matplotlib, and Hvplot and a Panel dashboard for ease of use. This analysis includes the number of housing units, sales price per square foot, gross rent, and the top ten most expensive neighborhoods per year.
